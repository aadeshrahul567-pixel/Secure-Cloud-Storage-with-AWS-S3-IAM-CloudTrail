# Secure-Cloud-Storage-with-AWS-S3-IAM-CloudTrail
A hands-on cloud security project demonstrating how to design, secure, and monitor a cloud storage solution on AWS — built from the perspective of a Cloud Security Analyst.
This project builds a secure cloud storage solution on AWS using S3 for storage, IAM for least-privilege access control, and CloudTrail + CloudWatch for activity monitoring and threat detection.

Role: Cloud Security Analyst Tools: AWS S3, IAM, CloudTrail, IAM Policy Simulator, S3 Storage Lens

What This Project Demonstrates
✅ Securely storing and serving files from S3
✅ Applying least-privilege IAM access
✅ Enabling logging and monitoring
✅ Detecting and remediating security misconfigurations
